# Ocean UI Library

Minimalist Angular component library aligned with Ocean Professional theme.

- Colors: primary #374151, secondary #9CA3AF, success #10B981, error #EF4444, surface #F9FAFB, text #111827, background #FFFFFF.
- Components: Button, Top Bar, Sidebar Nav, Avatar, Badge, Search Field, Table Header Row.

Import OceanUiModule in your application or Storybook stories.

```
import { OceanUiModule } from 'ocean-ui';
```

Use CSS variables to override theme if needed:

```
:root {
  --oc-primary: #374151;
  --oc-text: #111827;
}
```
